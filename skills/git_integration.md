# Git Version Control Skill

Use Git tools to inspect workspace state and create safe, clean commit checkpoints:

## Workflow:
1. Use `git_status` to view modified and untracked files in the workspace.
2. Use `git_diff` to review exact code changes made during the session.
3. After changes are tested and verified, stage them using `git_add`.
4. Create a concise, descriptive commit using `git_commit` (e.g., `git_commit` with message `"Fix login bug and add test coverage"`).
5. Never attempt automatic `git push`. Pushing changes must remain a manual user action.

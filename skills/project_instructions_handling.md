# Project Instructions Compliance Skill

Always check and enforce project-level guidelines located in `.agent/instructions.md`:

## Rules:
1. Before modifying any project, read and observe `.agent/instructions.md`.
2. Adhere to specified language versions (e.g., Python 3.13), naming conventions (e.g., `snake_case` for Python functions), schema rules, and coding styles.
3. Keep existing function names and public API contracts intact unless explicitly asked to modify them.
4. Always run project tests (`run_tests`) after modifications to ensure all existing behavior remains correct.
